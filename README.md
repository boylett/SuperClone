# SuperClone

[![Version](https://img.shields.io/badge/version-0.0.5-cb3837?style=flat-square&logo=npm&logoColor=white)](https://marketplace.visualstudio.com/items?itemName=boylett.superclone)

You have a repository. It has branches. You want all of them. Now you have all of them.

SuperClone clones every branch of a git repository into its own folder and opens the whole lot as a VS Code workspace. Pick a repo from your GitHub account or paste a URL, choose where to put it, and watch the progress bar do its thing.

</div>

## Install

Open the Extensions view in VS Code (`Ctrl/Cmd+Shift+X`), search for **SuperClone**, hit **Install** - or grab it from the [Marketplace](https://marketplace.visualstudio.com/items?itemName=boylett.superclone).

## Usage

Run **Git: Super Clone** from the command palette. Pick a repository from your GitHub account or paste a URL, choose a destination folder, and SuperClone fetches every branch into its own subfolder and opens them together as a multi-folder workspace.

## Commands

- **Git: Super Clone**
