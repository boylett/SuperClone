# SuperClone

You have a repository. It has branches. You want all of them. Now you have all of them.

SuperClone clones every branch of a git repository into its own folder and opens the whole lot as a VS Code workspace. Pick a repo from your GitHub account or paste a URL, choose where to put it, and watch the progress bar do its thing.

That's it. That's the extension.

## Usage

Run **Git: Super Clone** from the command palette.
